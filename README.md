# Guidana Site

Next.js marketing website for **Guidana Technologies LLC**.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## SEO routes

- `/` — Home
- `/about` — About Guidana & founder
- `/services` — Services index
- `/services/[slug]` — Individual service pages
- `/process` — Delivery process
- `/contact` — Contact
- `/get-started` — Project intake
- `/privacy-policy`, `/terms-of-service`, `/cookie-policy`
- `/sitemap.xml`, `/robots.txt`
